# Architecture Decision Records

Use an ADR to record a significant architectural or technical decision whose rationale should remain discoverable over time.

## Naming

Use sequential names such as `ADR-001-short-title.md`.

## Lifecycle

Typical statuses are `Proposed`, `Accepted`, `Superseded`, and `Deprecated`. Do not silently rewrite an accepted decision when the context changes; create a new ADR and link the superseded record.

## Template

Copy [`ADR-TEMPLATE.md`](ADR-TEMPLATE.md) when creating a decision record.
